Backpack Pickup Notify (1.20.1 Forge 47.x)
- Sends the vanilla "item taken" packet when Sophisticated Backpacks (magnet / pickup upgrade)
  moves an item into a backpack, so Loot Journal shows its notification.
- Server side only, no new blocks/items. Remove the jar to restore the original behaviour.
- Build: upload this folder to a GitHub repository -> Actions tab -> "build" -> Run workflow.
  The jar is in the run's Artifacts (backpack-pickup-notify-jar).
